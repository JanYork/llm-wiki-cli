# lwc v0.18.6

Fix Windows installation of Tutor, Book, and Practice runtimes when a valid ZIP omits its explicit parent directory entry.

## Highlights

- Accept the fixed runtime binary with or without a separate root directory entry. Windows release ZIPs can now pass the shared installer check; macOS and Linux archives remain compatible.

## Safety and compatibility

- Preserve checksum verification, exact binary paths, rejection of extra or duplicate entries, and extracted-file safety checks. No data migration is required.

## Verification

- Targeted Rust regression passed with the corrected validator and failed with the previous condition. The check compiled the source functions directly; a full local Cargo build was not completed.
- All 18 published v0.18.5 runtime archives (three components across six targets) passed SHA-256 verification, corrected listing validation, and extraction validation on macOS. This is archive compatibility evidence, not native execution on every operating system.
- Existing release CI performs its configured acceptance and native build gates before publication.

## Upgrade

Update the main LWC CLI to v0.18.6 using your usual installation channel, then retry the Tutor, Book, or Practice command. Updating or downloading only the component archive does not fix an older main CLI validator.
